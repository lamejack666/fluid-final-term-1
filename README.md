# Fluid Final Term 1

สรุปเฉลยวิชากลศาสตร์ของไหล บทที่ 4 การวิเคราะห์เชิงมิติ แบบจำลอง และความคล้ายคลึงกัน
(ตัวอย่างข้อ 7 และ ข้อ 8) อธิบายเป็นภาษาไทย ตามลำดับขั้นของอาจารย์

**เปิดอ่านออนไลน์:** https://lamejack666.github.io/fluid-final-term-1/

## เนื้อหาใน `index.html` (ไฟล์เดียว แยกเป็นแท็บ)
| แท็บ | เรื่อง |
|---|---|
| พื้นฐาน | เปลี่ยน km/hr เป็นมิติ M L T |
| ถาม-ตอบ | ระบบ M L T และการตั้งฟังก์ชัน |
| ข้อ 7 | แบบจำลองเครื่องสูบน้ำ: Q_m = 0.3 m³/s, ΔP_m = 10,000 kPa |
| ข้อ 8 | ลมพัดผ่านโครงสร้างสะพาน: H_m = 0.06 m, V_m = 4.78 m/s, f_p = 28.5 Hz |
