# Fluid Final Term 1

สรุปเฉลยวิชากลศาสตร์ของไหล บทที่ 4 การวิเคราะห์เชิงมิติ แบบจำลอง และความคล้ายคลึงกัน
(ตัวอย่างข้อ 7 และ ข้อ 8) อธิบายเป็นภาษาไทย ตามลำดับขั้นของอาจารย์

## เนื้อหาใน `index.html`
1. พื้นฐาน: เปลี่ยน km/hr เป็นมิติ M L T
2. ถาม-ตอบ: ระบบ M L T และการตั้งฟังก์ชัน
3. เฉลยข้อ 7: แบบจำลองเครื่องสูบน้ำ ($Q_m = 0.3$ m³/s, $\Delta P_m = 10\,000$ kPa)
4. เฉลยข้อ 8: ลมพัดผ่านโครงสร้างสะพาน ($H_m = 0.06$ m, $V_m = 4.78$ m/s, $f_p = 28.5$ Hz)
